# لوحة تحكم إدارة مكتب المحاماة (Admin Dashboard)

لوحة تحكم إدارية متكاملة وسريعة لإدارة حجوزات واستشارات مكتب المستشار بهاء البحيري.

## المميزات:
- إدارة ومتابعة الحجوزات ومواعيد الاستشارات.
- تصنيف نوع القضية (جنائي، مدني، أسرة، قضاء إداري).
- تأكيد الحجوزات أو إلغاؤها أو إكمالها وتحديث حالتها لحظياً.
- إدارة الخدمات القانونية والأسعار ومدة الاستشارة.
- متابعة رسائل واستفسارات التواصل الواردة من الموقع.
- إعدادات ساعات وأيام العمل الرسمية.

## التشغيل محلياً:
```bash
npm install
npm run dev
```

## البناء للإنتاج:
```bash
npm run build
```
